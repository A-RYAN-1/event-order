# Contributors

Everyone who has helped, in any way: code, issues, docs, review, ideas. The list is kept with the
[all-contributors](https://allcontributors.org) bot: comment `@all-contributors please add @user for code`
(or `doc`, `bug`, `ideas`, `review`, `example`) on an issue or pull request and the bot opens a
pull request that adds them.
