# Support

| You want to | Go to |
|---|---|
| Ask how to use it, choose a delay, compare with another tool | [Discussions](https://github.com/A-RYAN-1/event-order/discussions), after reading the [FAQ](docs/FAQ.md) and `go doc -all` |
| Report a bug | An issue with the bug form: the events (key, event time, arrival order), what you expected and what you got |
| Propose a feature | An issue with the feature form, before writing code |
| Report a security problem | `SECURITY.md`, never a public issue |
| Contribute | `CONTRIBUTING.md` and the issues labelled `good first issue` or `help wanted` |

This is a one-maintainer project. Expect a first reply within a few days, not hours, and no guaranteed response time. Questions in Discussions are public so the next person can find the answer.
